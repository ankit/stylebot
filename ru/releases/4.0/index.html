Обновлённый редактор

Переписан с нуля, теперь с тёмным режимом.

  • Сгруппированные настройки, которые показывают значения самой страницы
  • Улучшенный подбор селекторов: они продолжают работать после обновления сайта, и можно выбрать другой
  • Видно, когда значение переопределено другим правилом
  • Цветовые палитры и пипетка
  • Предпросмотр цвета или шрифта на странице при наведении
  • Любое другое свойство CSS можно изменить прямо в разделе «Другие свойства»
  • Отмена изменений

Stylebot в терминале

Управляйте Stylebot из командной строки или поручите это агенту для программирования, например Claude Code, Codex или Cursor. Агент меняет оформление сайтов прямо в вашем браузере и использует вашу подписку, а не API-ключ.

$ npm install -g @stylebot/cli
Настроить CLI →

Для Chrome или Edge. В Firefox командная строка пока не работает.

# Открывает страницу в окне позади вашего и выводит ID её вкладки.$ stylebot open news.ycombinator.com
# Выводит видимые элементы страницы в виде структуры.$ stylebot outline 54432929
# Сохраняет CSS как стиль сайта, применяет его и проверяет страницу.$ stylebot css set news.ycombinator.com < dark.css
# Сохраняет снимок вкладки.$ stylebot screenshot 54432929 -o page.png

Профили

Храните несколько вариантов оформления для сайта и переключайтесь между ними в редакторе или во всплывающем окне.

Боковая панель или отдельное окно

В Chrome и Edge редактор открывается на боковой панели. Его можно вынести в отдельное окно через пункт Положение в меню редактора ⋯.

История версий

Каждое изменение сохраняется, и можно восстановить любую прежнюю версию.

Синхронизация

Синхронизация через Google Drive стала надёжнее. Изменения с разных компьютеров объединяются, поэтому ничего не теряется. Она запускается сама каждые 30 минут и сразу после правки.

И не только

  • Новый сайт stylebot.dev
  • Новый значок Stylebot
  • Стили теперь применяются и внутри Shadow DOM, поэтому работают на сайтах, построенных на веб-компонентах
  • Горячие клавиши Stylebot теперь задаются в настройках сочетаний клавиш браузера. В Chrome и Edge изменённые вами сочетания сброшены к значениям по умолчанию, поэтому задайте их там заново.
  • Stylebot теперь доступен на вьетнамском
