Stylebot dal terminale

Controlla Stylebot dalla riga di comando, oppure lascia che lo faccia un agente di programmazione come Claude Code, Codex o Cursor. L’agente personalizza i siti direttamente nel tuo browser, usando il tuo abbonamento invece di una chiave API.

Configurazione

  1. Installa Stylebot

    Per Chrome o Edge. La riga di comando non funziona ancora su Firefox.

    Aggiungi a ChromeAggiungi a Edge

  2. Installa la CLI

    Richiede Node 20 o versioni successive.

    $ npm install -g @stylebot/cli

  3. Collegala ai tuoi browser

    Così la CLI viene registrata in Chrome ed Edge e Stylebot può raggiungerla.

    $ stylebot install

  4. Attiva l’accesso da riga di comando

    Nelle opzioni di Stylebot, in Generali, attiva Consenti l'accesso da riga di comando e concedi ciò che chiede il browser.

  5. Aggiungi il plugin per Claude Code Facoltativo

    In Claude Code, esegui:

    $ /plugin marketplace add ankit/stylebot
    $ /plugin install stylebot@stylebot

    Poi provalo:

    $ /stylebot news.ycombinator.com give it a dark theme

Comandi

Li esegue un agente per te, ma puoi eseguirli anche tu. stylebot --help li elenca tutti.

$ stylebot open news.ycombinator.com
Apre la pagina in una finestra dietro la tua e stampa l’ID della scheda.
$ stylebot outline 54432929
Stampa gli elementi visibili della pagina come struttura.
$ stylebot css set news.ycombinator.com < dark.css
Salva il CSS come stile del sito, lo applica e controlla la pagina.
$ stylebot screenshot 54432929 -o page.png
Salva un’immagine della scheda.

Privacy

L’accesso da riga di comando è disattivato finché non lo attivi. Quando è attivo, le app di questo computer possono leggere le pagine che hai aperto, acquisire screenshot e modificare i tuoi stili. Puoi disattivarlo in qualsiasi momento nelle opzioni di Stylebot.

Stylebot e la CLI comunicano solo tra loro, su questo computer, e non inviano nulla altrove. Un agente invia ciò che legge al proprio provider, come fa Claude Code con Anthropic.
