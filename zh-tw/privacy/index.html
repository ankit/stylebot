隱私權

Stylebot 沒有伺服器、沒有帳戶，也沒有分析工具，不會收集、販售或分享你的資料。只有在你使用下列功能時，資料才會離開你的瀏覽器。

最後更新：2026年10月12日

這是翻譯版本。如與英文版本有出入，以英文版本為準。

瀏覽器中的資料

你的樣式、設定和記錄都儲存在瀏覽器中，解除安裝 Stylebot 就會移除這些資料。Google Fonts 字型和透過 @import 匯入的樣式表會從其託管位置下載，託管方會看到你的 IP 位址。

Google Drive 同步

在選項中連線 Google Drive 後，你的樣式會儲存到你自己 Drive 中的一個檔案。Stylebot 只看得到它自己建立的檔案，它的存取權杖保存在你的瀏覽器中。你可以在選項或你的 Google 帳戶中中斷連線。

Stylebot 對於從 Google API 取得之資訊的使用方式，遵循 Google API 服務使用者資料政策，包括「有限使用」規定。

命令列

在選項中開啟 允許命令列存取 後，以你的身分執行的應用程式就能透過本機連線讀取你的分頁、頁面和樣式，擷取螢幕畫面，以及變更你的樣式。它們讀取的內容可能會傳送到它們使用的服務，例如程式設計代理的模型。
